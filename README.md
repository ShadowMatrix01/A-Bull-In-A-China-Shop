This game is compatible with Windows 10/11. For Linux and MacOS compatibility, please use this version.

Unfortunately, PyGame has very limited controller support. Therefore, This game recommends Steam Input for controller support. 
Steam and Steam Input are trademarks of Valve Corporation. This project is not affiliated with or endorsed by Valve.

To use a controller with this game:

1: Add the game to Steam as a non-Steam game.

2: Open Steam, go to Settings > Controller > General Controller Settings, and enable your controller type.

3: Customize the controller to map to the following actions UP(ARROW UP, SPACE, OR W), DOWN (ARROW DOWN OR S), LEFT (ARROW LEFT OR A), RIGHT (ARROW RIGHT OR D), ACTION BUTTON (ENTER KEY), SPECIAL(E KEY), DASH (LEFT OR RIGHT SHIFT).

4: Launch the game through Steam to enable Steam Input! :D

NEW: New optimizations to the game now have it running on machines that have under 1gb or ram available at all times, instead of the old 2.3 gb of ram usage, a 78.8724% reduction.

To Run, download all of the files, and run the python file. You may need to pip install pygame and other libraries.

You may get a prompt from your antivirus for permission to allow it to run, please allow it.

This game is tested to run well at a 1920 x 1080 resolution at 60 frames per second on a 144hz display, while it should work on higher resolutions, no guarantees are made for any other resolution other than this one.

WARNING: This game runs on PyGame, which requires a fairly recent CPU to run well. This is NOT due to the code or the assets of my game, but is a well documented result of the PyGame library. Make sure that your CPU is set to MAXIMUM Performance, otherwise the game will not run well!
